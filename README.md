# React Ecosystem Course

An interactive, single-page learning experience designed to help you understand the core pieces of the modern React ecosystem. This project walks through routing, forms, validation, and state management with practical examples and built-in exercises.

## What You'll Learn

- React Router v7 (navigation, nested routes, layouts)
- Controlled forms and manual validation
- React Hook Form for efficient form handling
- Context API for global state
- useReducer for complex state logic

## Features

- Clean, modern UI with sidebar navigation
- Interactive code examples
- Built-in quizzes to test understanding
- “Fix the bug” challenges with solutions
- Progress tracking as you scroll

## Usage

1. Download or clone the repository
2. Open the HTML file in your browser
3. Use the sidebar to navigate through sections
